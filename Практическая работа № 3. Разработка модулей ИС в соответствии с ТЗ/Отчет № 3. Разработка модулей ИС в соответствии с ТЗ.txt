Цель работы: разработать основные модули информационной системы.
В ходе практической работы создана структура проекта (фронтенд, бекенд, БД), реализованы класс Database для работы с SQLite и базовые маршруты Flask: 
регистрация, авторизация, просмотр страниц; применён объектно-ориентированный подход.
Вывод: в результате работы разработаны основные модули ИС и разделение логики на фронтенд и бекенд.
Оснащение: Windows, VS Code, Python 3, Git. Требования: работающие модули, коммиты.
